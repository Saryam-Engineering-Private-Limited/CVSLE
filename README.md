# CVSLE Library

## Overview

The **CVSLE (Continuous Variable Speed Load Electronics)** library is a C library designed for precise speed control of AC loads using a triac. Specifically optimized for AVR microcontrollers, CVSLE allows for efficient phase-angle control to modulate the power delivered to loads like motors or dimmable lights.

## Features

- **Phase-Angle Control**: Modulates the AC waveform's phase delay to control the average power delivered to your load.
- **AVR Compatibility**: Seamlessly integrates with AVR microcontrollers, including the ATmega series, ensuring optimal performance.
- **Configurable Parameters**: Customize phase delays and control settings to tailor the system to your specific application needs.
- **Real-Time Operation**: Provides accurate and responsive control, suitable for real-time applications.

## Requirements

- **AVR Microcontroller**: Compatible with AVR devices, such as those in the ATmega series.
- **C Compiler**: Requires a C compiler for AVR development, such as AVR-GCC.
